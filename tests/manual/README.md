# Manual Test Runner

> **This is a tool for collection maintainers.**
> It runs every module against real hardware before a release and keeps the output as evidence.
>
> **You do not need it to use the collection or to contribute to it.**
> It requires a physical PRIMERGY server, and some cases power the server on and off,
> delete RAID arrays, or flash firmware.

The documentation is written in Japanese: **[README_ja.md](README_ja.md)**.
